UTS (Ulangan Tengah Semester) - Web Portofolio Tim

Proyek penugasan Ulangan Tengah Semester (UTS) mata kuliah Pemrograman Web yang berfokus pada perancangan dan implementasi website portofolio tim secara responsif. Menerapkan tata letak persis sesuai rancangan wireframe, sistem variabel warna terstandarisasi (Dark Chocolate, Milk Tea, Misty Rose), pengalihan tema terang & gelap (Light/Dark mode) dengan penyimpanan localStorage, validasi formulir interaktif, serta pembagian peran kolaboratif antar anggota tim.

Tecnology

HTML5 Semantik CSS Grid & Flexbox Vanilla JavaScript LocalStorage Theme Responsive Design
